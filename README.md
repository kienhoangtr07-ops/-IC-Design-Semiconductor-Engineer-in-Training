## Projects

### Project 1 — Mini 4-bit ALU

A small combinational Arithmetic Logic Unit designed and simulated using Logisim-evolution.

**Main functions:**

- 4-bit AND
- 4-bit OR
- 4-bit XOR
- 4-bit addition
- 4-to-1 multiplexer result selection
- Carry-out for addition

**Design highlights:**

- Modular functional blocks
- 4-bit Ripple Carry Adder
- Four reusable 1-bit Full Adders
- Block-level and integration testing
- Debugging of a Full Adder carry issue
